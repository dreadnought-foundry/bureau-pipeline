## What the CEO sees

On 9 August a newly available, more expensive model promoted itself onto the whole fleet with nobody deciding it, and agents ran out of usage mid-run.

Today, every agent run reads its model from one place outside every code base. That held in our own organization, in a project in EveryBite's, and in the daily model review. Before that place existed, a run that could not read it still started on the built-in defaults and said so plainly on its card. What gets written there names a role, never a person.

What protects the fleet now: the console offers only the choices the rules allow, nothing automatic climbs a list, and a run that cannot read its model choice runs on the defaults and says so.
