## What the CEO sees

On 9 August a newly available, more expensive model promoted itself onto the whole fleet with nobody deciding it, and agents ran out of usage mid-run.

The old way of changing a model is gone. A choice used to travel from the console as a pull request into the pipeline, and copies of it sat in several files that a person could edit thinking it changed something. Those files and the route that wrote them no longer exist in either code base. The last such pull request was opened on 24 October, and none has been opened since the route was removed on 27 October.

Each code base now has a test that names every place a copy used to live. The test fails if a copy comes back, and it passed on the released code of both. The pipeline's settings file now holds only facts about the code, never a choice. The background checks that kept testing the old route are also gone. In the last test run before they were removed, they took about five and a half hours of runner time.

What protects the fleet now: the page offers only what the rules allow, nothing automatic climbs a list, and the console keeps a history with an undo.
